What It Does

🔒

On-chain Access Control

Patients grant and revoke doctor access via smart contract — no central authority, no backend can override it.

👤

3 User Roles

Patient, Doctor, and Lab — each role sees a different dashboard and has different write permissions on-chain.

📋

Prescriptions & Reports

Doctors update prescriptions on-chain. Labs upload reports. Patients can view everything tied to their profile.

🔐

keccak256 Password Hashing

Passwords are hashed with keccak256 before being stored in the contract — never stored in plaintext.
