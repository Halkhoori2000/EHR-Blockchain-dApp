User Roles

userType = 1
Patient
  • Register & login via contract
  • Update profile (phone, symptoms, description)
  • Grant access to a doctor
  • Revoke doctor access
  • View own prescription & lab reports
userType = 2
Doctor
  • Register & login via contract
  • View list of authorised patients
  • Read patient profile (symptoms, history)
  • Write prescription to patient record
userType = 3
Lab Person
  • Register & login via contract
  • View patient list
  • Write lab report to patient record

Smart Contract Functions

FunctionTypeDescription
createUser(name, username, password, userType) Write Registers a new user; stores keccak256(password) hash; creates Patient or Doctor struct based on userType
loginUser(username, password) Read Returns User struct if keccak256(password) matches stored hash; free to call
getPatientProfile(username) Read Returns full Patient struct: name, phone, symptoms, description, prescription, reports
addAccessToDoctor(doctorUsername, patientUsername) Write Patient grants a doctor access by appending patientUsername to the doctor's patients array on-chain
removeAccessToDoctor(doctorUsername, patientUsername) Write Patient revokes access; finds and removes patientUsername from doctor's array
updatePrescription(patientUsername, prescription) Write Doctor writes prescription string directly to patient's on-chain profile
updateReports(patientUsername, reports) Write Lab person writes lab report string to patient's on-chain profile
